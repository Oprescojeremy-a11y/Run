Comment ça marche

RunLoop utilise la position GPS de ton navigateur puis recherche plusieurs boucles en s’appuyant sur le réseau OpenStreetMap et le moteur de calcul un moteur de routage piéton OpenStreetMap. La distance affichée est celle du tracé calculé, pas un cercle théorique.

La localisation est demandée uniquement lorsque tu appuies sur le bouton. Pour que le GPS fonctionne sur iPhone, cette page doit être hébergée sur une adresse HTTPS ; un fichier HTML ouvert depuis Téléchargements ne suffit pas. Autorise ensuite la localisation dans Safari et utilise une connexion internet.
